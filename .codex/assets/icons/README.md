The named app icons use the unchanged paths from `.codex/references/deepseek_html_20261020_60ee13.html`.
The root SVG supplies the HTML `.icon` style: no fill, 1.75 stroke, round caps and joins.

`backspace.svg` is the HTML keypad character U+232B, converted from the Windows Segoe UI Symbol glyph to a vector graphic. This keeps the reference glyph visible on devices that lack it. The font file is not distributed.

The app logo remains the supplied `assets/dzd.svg`.
