# Waffir fonts

Geist is used for Latin text and amounts. Geist Mono is used for section labels. Rubik is assigned to Arabic text, as specified in the HTML. Platform glyph fallback applies where a font has no matching glyph.

The bundled static weights were generated from the Google Fonts variable files with fontTools. Source files and licenses:

- https://github.com/google/fonts/tree/main/ofl/geist
- https://github.com/google/fonts/tree/main/ofl/geistmono
- https://github.com/google/fonts/tree/main/ofl/rubik

Each family includes its SIL Open Font License. Fonts load from the APK without a network connection.
