Anatomy

What's inside every button.

Padding, icon gap, and label tracking are all tied to the size token. Corner radius is fixed at 14px across every size.

54 px height

Height · Large

Large buttons are 54px. Medium is 44px. Small is 36px. Icon-only buttons follow the same height and stay square — they use the same 14px radius, not 50%.

Padding · Icon · Gap

Horizontal padding is 28px on large, 22px on medium, 16px on small. Icon-to-label gap is 8px / 8px / 6px. Label tracking is -0.01em.

radius: 14px

Radius · Fixed at 14px

All buttons use --btn-radius: 14px. Not a pill (999px), not a circle (50%). The same radius applies to every size, so the shape language stays consistent from small inline controls to full-width onboarding CTAs.
